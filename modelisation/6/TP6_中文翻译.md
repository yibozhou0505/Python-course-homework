## 练习 1（复合求积方法的实现）

在本练习中，我们将通过把区间 `[a,b]` 做规则划分，来近似计算该区间上的积分。

1. 在下面的程序中，我们用左矩形法对函数 `f` 进行积分：

```python
import math as np
def f(x) :
    return np.cos(x)

def integraleG(f,a,b,N) :
    h=(b-a)/N
    t=[a+i*h for i in range(N)]
    IN=0.
    for i in range(N) :
        IN+=h*f(t[i])
    return IN
```

验证该方法确实是一阶方法：在 Python 中，对函数 `cos` 在区间 `[0, π/2]` 上积分，并取不同的 `N` 值进行测试。

2. 修改前一个方法，得到梯形法 `integraleT(f,a,b,N)`。验证它是二阶方法。

3. 编写函数 `integraleM(f,a,b,N)`，使用中点法。将结果与 `integraleT(f,a,b,N)` 给出的结果进行比较。

4. 编写函数 `integraleS(f,a,b,N)`，使用 Simpson 方法。验证它确实是四阶方法。

5. 使用函数 `integraleS` 计算函数 `x ↦ √x` 在区间 `[0,1]` 上的积分。该方法关于 `N` 的收敛速度是多少？你能给出解释吗？
