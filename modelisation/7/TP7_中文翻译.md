## `random` 的基本介绍

回顾一下，导入 `random` 库可以这样写：

```python
import random as rd
```

这行代码只需要在文件开头写一次，用于导入随机库。

当我们想要模拟随机现象时，这个库里有一些很实用的方法。本 TP 中主要会用到其中两个：`random` 和 `randrange`。

1. 函数 `random` 会在区间 `[0,1]` 上均匀地产生一个随机实数。  
   因此，它模拟的是区间 `[0,1]` 上的连续均匀分布随机变量。

2. 函数 `randrange` 会在给定的 `range` 中均匀地取一个整数。  
   因此，它模拟的是某个有限整数区间上的离散均匀分布随机变量。

下面给出一个简单示例：

```python
U = rd.random()
E = rd.randrange(2,10,3)
```

这时：

- `U` 是一个介于 `0` 和 `1` 之间的实数；
- `E` 是集合 `{2,5,8}` 中的一个整数。

一般来说，`rd.randrange(debut,fin,pas)` 会从集合

```text
Jdebut, fin - 1K ∩ {debut + k·pas, k ∈ N}
```

中随机返回一个整数。

### 练习 6

可以用概率方法来计算面积。这里给出一个简单例子。  
在 `[0,1]` 中独立均匀地选取 `x` 和 `y`，于是点 `(x,y)` 落在正方形 `[0,1]^2` 中。

注意到：

```text
P(x^2 + y^2 ≤ 1) = π / 4
```

这正对应于圆心在 `(0,0)`、半径为 `1` 的四分之一圆的面积。

于是我们得到一种近似计算的方法：  
随机抽取 `n` 个点 `(x1,y1), ..., (xn,yn)`，则概率 `P(x^2 + y^2 ≤ 1)` 的一个近似值可以写成：

```text
Card({(xi, yi), xi^2 + yi^2 ≤ 1}) / n
```

编写函数 `approx(n)`，输入整数 `n ≥ 1`，按上述方法返回 `π/4` 的一个近似值。
