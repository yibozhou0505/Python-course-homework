## 练习 1（预备上手）

先确认 `numpy` 和 `matplotlib` 能正常导入，运行下面的程序：

```python
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0.0001, 2*np.pi, 1000)
y = np.sin(100/x)
plt.plot(x, y)
plt.show()
```

Fourier 变换使用命令 `np.fft.fft(y)`，逆 Fourier 变换使用 `np.fft.ifft(z)`。下面的程序可以把频率重新居中到 `[-N/2, N/2]` 并显示 `y` 的 Fourier 变换：

```python
z = np.fft.fft(y)
N = z.size
fq = np.arange(-np.floor(N/2), N - np.floor(N/2))
plt.plot(fq, np.abs(np.fft.fftshift(z)))
plt.show()
```

我们还需要操作复数。复数可以写成 `2+3j`，也可以写成 `complex(2,3)`，表示 `2 + 3i`。对一个向量 `y`，可以用 `y.real` 和 `y.imag` 取实部和虚部，用 `np.abs(y)` 取模。

## 练习 3（热方程）

我们希望模拟金属棒中的温度演化。设

```text
f : R+ × R -> R,   (t,x) -> f(t,x)
```

表示温度，并且关于空间变量 `x` 是 `1` 周期的。初始条件为 `x -> f(0,x)`。物理方程给出：

```text
∂f/∂t = ∂²f/∂x².
```

把空间变量 `x` 做 Fourier 变换：

```text
f(t,x) = sum c_n(f)(t) e^(2iπnx),
```

可得到对每个 `n ∈ Z` 的微分方程：

```text
c_n(f)'(t) = -(2πn)^2 c_n(f)(t).
```

积分后得到：

```text
c_n(f)(t) = exp(-(2πn)^2 t) c_n(f)(0).
```

1. 实现函数 `temperature(f0,t,N)`：给定初始状态 `x -> f0(x)`，计算时间 `t` 时的温度，并以向量

```text
( f(t,x_k) )_{0≤k≤N-1},   x_k = k/N
```

的形式返回。

2. 将这个方法应用于初始条件：

```text
f(0,x) = 1,  if 7/16 ≤ x ≤ 9/16,
         0,  otherwise.
```

画出 `t = 0, 10^(-3), 2·10^(-3), ..., 10^(-2)` 时的温度。

## 练习 4（周期函数插值）

设 `N ≥ 1`，`f` 是一个实值 `1` 周期函数，并且已知它在点

```text
k/N,   0 ≤ k ≤ N-1
```

处的值。设 `φ` 是一个实函数，并满足：

```text
∫_R φ(t) dt = 1.
```

定义

```text
φ_{N,k}(t) = φ(Nt - k),   0 ≤ k ≤ N-1,
```

以及它的周期化：

```text
φtilde_{N,k}(t) = sum_{n∈Z} φ_{N,k}(t+n).
```

1. `(*)` 验证：

```text
φtilde_{N,k}(t) = φtilde_{N,0}(t - k/N).
```

证明：  
由定义，

```text
φtilde_{N,k}(t)
= sum_n φ(N(t+n)-k)
= sum_n φ(N(t-k/N+n))
= φtilde_{N,0}(t-k/N).
```

2. `(*)` 我们希望计算系数 `(c_k)_{0≤k≤N-1}`，使

```text
S_N(t) = sum_{k=0}^{N-1} c_k φtilde_{N,k}(t),   t ∈ [0,1]
```

插值 `f` 在点 `k/N` 处的值，即

```text
sum_{k=0}^{N-1} c_k φtilde_{N,k}(l/N) = f(l/N),   0 ≤ l ≤ N-1.
```

令

```text
f_l = f(l/N),   h_l = φtilde_{N,0}(l/N).
```

由第 1 问，

```text
φtilde_{N,k}(l/N) = φtilde_{N,0}((l-k)/N).
```

因此插值条件等价于周期卷积方程：

```text
sum_{k=0}^{N-1} h_k c_{l-k} = f_l,   0 ≤ l ≤ N-1,
```

其中下标按 `N` 取模。这个方程可以用离散 Fourier 变换快速求解：

```text
FFT(h * c) = FFT(h) FFT(c),
FFT(c) = FFT(f) / FFT(h).
```

3. 编写函数 `filtre(phi,N,M)`，返回

```text
h_k = φtilde_{N,0}(k/N),   0 ≤ k ≤ N-1,
```

其中用有限和近似周期化：

```text
φtilde_{N,0}(t) ≈ sum_{m=-M}^{M} φ(N(t+m)).
```

4. 编写函数 `interpole(f,phi,N,M)`，快速计算系数 `(c_k)`。

5. 应用该方法，其中

```text
φ(t) = 1/(σ√π) exp(-t²/σ²),   σ = 1,
f(t) = sin(10π / (|t - 1/2| + ε)),   ε = 10^(-2),
```

并取 `N = 1000`。注意在机器精度下，当

```text
t ∈ [k/N - 1/2, k/N + 1/2]
```

时，`φtilde_{N,k}(t) = φ_{N,k}(t)`，因此可以取 `M = 0`。

6. 编写函数 `somme(ck,phi,N,M)`：给定系数 `(c_k)`，返回

```text
S_N(t) = sum_{k=0}^{N-1} c_k φtilde_{N,k}(t)
```

在点 `t = k/N`，`0 ≤ k ≤ N-1` 处的值。
